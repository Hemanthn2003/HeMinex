## 🎨 Design Philosophy

The website follows a futuristic **digital systems / technology** aesthetic.

The visual language combines:

- Deep-space inspired backgrounds
- Neon blue and gold accents
- PCB circuit patterns
- Technology grids
- Glowing UI elements
- Animated particles
- Cinematic transitions
- Minimal futuristic typography
- High-contrast interfaces

The goal is to create a digital presence that feels **premium, technical, modern, and memorable**.
